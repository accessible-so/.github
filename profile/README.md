# Accessible: AI accessibility testing
     
  [Accessible](https://accessible.so) is an AI accessibility testing platform for websites and web apps. It
  tells you what actually blocks people with disabilities from using your site, and gives you dated
  evidence that you fixed it.

  Automated scanners check the code of a page. Many accessibility problems only show up when someone tries
  to do something: sign up, check out, or fill out a form with a keyboard or a screen reader. Accessible
  tests at three layers:

  - **[Automated scanning](https://accessible.so/product/automated-scanning)**: WCAG 2.2 checks with
  axe-core on every page, on a schedule or on each deploy.
  - **[Journey testing](https://accessible.so/product/journey-testing)**: AI agents act as a keyboard and
  screen reader user, complete real tasks, and report exactly where the journey breaks.
  - **[Real user monitoring](https://accessible.so/product/real-user-monitoring)**: one script tag finds
  barriers in real production sessions, including states a crawler never reaches, and ranks them by how
  many people hit them.

  Accessible diagnoses. It is not an overlay: it doesn't inject code into your pages or promise automatic
  compliance.
